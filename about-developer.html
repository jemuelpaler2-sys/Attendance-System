Project Information

Introducing SmartRoll and the purpose behind it.

SmartRoll is a Student Attendance Management System developed for Nonok Norte National High School. It replaces paper-based attendance registers with a centralized workspace for administrators, teachers, and students.

Its main purpose is to make attendance recording, monitoring, and reporting faster and more accurate, while keeping student information organized in one place.

System development

SmartRoll was developed using PHP and MySQL on a XAMPP environment, following a structured system analysis and design process. The system was built with a responsive interface, role-based access, and a centralized database to support reliable attendance recording and reporting for Nonok Norte National High School.
